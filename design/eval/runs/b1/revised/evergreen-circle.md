## Verdant: The Evergreen Circle (Ritualists)
Pitch: Every rite returns, renewed.
Verbs: echo (copy a space's or ability's effect), plant
Scoring: Perennial. At round end, each player gains +1 follower per echo they made this round, max I 1 / II 1 / III 2.
Emits: echo, give (Mirror Twin)
Consumes: rivals' spaces (Mirror), rivals' members (Graft), echoes from any source (Perennial, Tend)

Echo rule (printed on the board edge): An echo copies an effect only. You don't take that space, you still buy from the Verdant stall, and it doesn't count toward other spheres' scoring or contests. Spaces whose own effect is an echo can't be echoed. Each echo action counts as one echo, and it counts as made before it resolves.

Notes:
- Termination: an echo never copies a space or ability that is itself an echo. Renewal copies 2 spaces but counts as one echo. Timekeeper triggers once per round. The tray is capped, so a second Plant in the same window, from Timekeeper or Return, gives only its +1 verdant.
- Perennial is printed on each ring, and anyone who echoes scores it. Verdant's spaces are a lure for the whole table, which is deliberate. The 1/1/2 caps (game max 4, about 6u) stop a Verdant dweller maxing it with ordinary picks, which was ~9u flat at 1/2/3. The "game total" line is dropped because the caps already imply it. The name changed from "The Rite" to avoid Violet's scoring rule of the same name.
- Mirror and Return can't copy the ring-III center. That keeps the center contest real and stops a round-I space from yielding ~10u in round III (observed in mind-play). Mirror still grows with the rings: copying a ring-II space in round III is about 4u, plus Perennial and Circle Elder.
- Return now looks only at last round, which keeps the history it checks short. It always has a target from round II on, at about 3–4u plus a Perennial tick.
- Graft: the fallback is now a choice, so Graft is never below 3u. Only triggered abilities can be copied; passive and round-start abilities are excluded and greyed out in the UI, and the UI previews what each choice would yield.
- Tend: 2 / 3 in round I, 2 / 4 in round II, 2 / 5 in round III. It no longer goes dead late.
- Plant: the tray returns before that placement's effect and buy. Resources on the tray count as held for every round-end tally. If this is your last placement of the game, the tray returns at once. The tray and the "next placement" timer are a player-panel element (L5 warn), and Plant runs exactly 12 words.
- Mirror Twin: actor +2, rival +1, so the spill ratio is 0.5 and the actor gains well over 1.5u. Choosing which rival to copy steers about 1u per echo. That's small and accepted (a kingmaking watch item).
- Values: Tend 2–3 / 4 / 5; Mirror ~2.5 + Perennial tick (R1 ~4u, justified as the sphere's lure, since every round-I space fills anyway); Plant ~3; Return ~3.5; Graft ≥3; Renewal ~6.5 + Elder 1 + tick ≈ 9u, the top of the round-III band and the intended burst.
- Members: Seedling 1/~2.75 (~36%, cheap-recruit tier); Gardener 2/~3; Mirror Twin 3/~5 (60%); Circle Elder 4/~6.3 (63%); Timekeeper 5/~7.5 (67%); World Tree 7/~9.5 (74%: 3 followers plus ~+2–3 per Plant, ~2 uses). Watch: in mind-play, Timekeeper could only be bought in round III. If that repeats, swap the costs of Timekeeper and Circle Elder.
- Silo index ~0.55: Mirror, Graft and Mirror Twin need the table; Return and Renewal are self-echoes.
- Lints: L1 pass, L2 pass, L3 pass, L4 n/a, L5 warn (tray), L6 pass, L7 pass, L8 pass, L9 pass (Echo rule written out), L10 pass.
