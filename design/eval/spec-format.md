# Quadrant Spec Format

Use this format for anything you send through the evaluator. For partial ideas, leave unknown fields as `?`.

```
## <Color>: <Sphere name> (one-word persona)
Pitch: <five words or fewer>
Verbs: <the 1–3 elemental verbs this quadrant owns>
Scoring: <one rule; the value printed on rings I / II / III>
Emits: <generic signals it creates (see value-model.md → Shared vocabulary)>
Consumes: <generic signals it profits from>

| Ring | Action | Effect (≤14 words) |
| I | ... | ... |   ×3
| II | ... | ... |  ×2
| III | ... | ... | ×1

| Member | Cost | Effect (≤14 words) | Extra followers |   ×6, spread across costs 1–7. Each member is already worth 1 follower; this column lists any followers beyond that

Notes: <intended combos, known risks>
```
